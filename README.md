# Forecasting-the-S-P-500-Index-Using-Recurrent-Neural-Networks
Collected and preprocessed historical S&amp;P 500 data, performing normalization and feature sequencing for time-series modeling. Evaluated RNN, LSTM, GRU, and Bi-GRU models, interpreting performance metrics (best RMSE = 43.8, MAE = 30.79) to support short- and medium-term forecasting for trading applications.
